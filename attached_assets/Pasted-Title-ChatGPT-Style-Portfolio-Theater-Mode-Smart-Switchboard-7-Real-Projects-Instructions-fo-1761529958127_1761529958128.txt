Title: ChatGPT-Style Portfolio — “Theater Mode” Smart Switchboard (7 Real Projects)

Instructions for the Agent:

Build a sleek, ChatGPT-like portfolio site in React + Tailwind, where the homepage is the chat interface.
There is no AI — responses are canned and keyword-matched (“theater mode”), but the experience should feel conversational, fast, and alive.

1. Tech & Structure

Framework: React/Next.js (Tailwind CSS styling).

One main route / showing the chat interface.

Local state only — no API calls, no backend.

Dark ChatGPT-like layout with collapsible left sidebar, chat area, and sticky input.

2. Layout & Style
Left Sidebar

Top: “New Chat” (clears conversation).

Section: “Quick Prompts” — chips/buttons for
Tour, Recent Work, Case Studies, Process, Pricing, Contact, About

Section: “Project Categories” — toggles
Web Apps, Design, Branding, UI/UX, Photography, Concepts, Marketing

Footer: “Portfolio Chat — Theater Mode”

Main Chat Area

Header: small monogram left, nav links right (Work, About, Contact)

Chat bubbles: user on right, bot on left

Fake typing animation (600ms)

Welcome message on load:
“👋 Hi, I’m Marco’s portfolio copilot. Ask me about a project, my process, or try a quick tour.”

Input placeholder: “Ask about my work (e.g., ‘Show me the soccer site’ or ‘process’)”

Quick chips under input: Tour · Projects · Process · Contact · About

6. Chat Behavior

When user types, system detects keywords → returns a matching canned reply or project card.

Multiple matches → show “Results Reel” (up to 3 projects).

Typing animation delay for realism.

"New Chat" resets to welcome message.

7. Components

ReplyCanned – for text-based canned responses

ReplyProjectCard – for single project feature

ReplyReel – for multi-project grid

ReplyContact – for call-to-action

MessageList – stores conversation history (max 10 exchanges)
